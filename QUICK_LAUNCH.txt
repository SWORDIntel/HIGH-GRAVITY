  HIGH-GRAVITY WINDSURF QUICK LAUNCH COMMANDS - COPY & PASTE

┌─ DASHBOARD SHORTCUTS ─────────────────────────────────────────────────────┐
│ Run: python3 hg.py                                                         │
│ Then press:                                                                │
│   P - Patch Windsurf client                                                │
│   W - Launch Windsurf (--dangerously-bypass-approvals-and-sandbox)         │
│   S - Launch Gemini AI Studio (-y auto-approve)                            │
│   G - Launch Gemini Chat (-y auto-approve)                                 │
│   A - Toggle Aliases display                                               │
│   E - Toggle Pegasus Swarm panel                                           │
│   1 - Spawn Agent (random API key)                                         │
│   2 - Checkpoint Swarm                                                     │
│   3 - Terminate Swarm                                                      │
│   4 - E2E Code Audit                                                       │
│   X - Git Push to origin/main                                              │
│   C - Clear cache                                                          │
│   R - Rotate keys                                                          │
│   Q - Quit                                                                 │
└────────────────────────────────────────────────────────────────────────────┘

┌─ COMMAND LINE LAUNCHES ───────────────────────────────────────────────────┐
│                                                                            │
│ Windsurf (basic):                                                          │
│ bin/gemini_session_launcher.py --mode windsurf --provider proxy \         │
│   --proxy-url http://localhost:9999                                       │
│                                                                            │
│ Windsurf (with key index 1):                                               │
│ bin/gemini_session_launcher.py --mode windsurf --provider proxy \         │
│   --proxy-url http://localhost:9999 --key-index 1                         │
│                                                                            │
│ Gemini AI Studio:                                                          │
│ bin/gemini_session_launcher.py --mode studio                              │
│                                                                            │
│ Gemini Chat:                                                               │
│ bin/gemini_session_launcher.py --mode chat                                │
│                                                                            │
│ Gemini Studio (with specific key):                                        │
│ bin/gemini_session_launcher.py --mode studio --key-index 1                │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ PIPED JSON LAUNCHES ─────────────────────────────────────────────────────┐
│                                                                            │
│ Basic (one-liner):                                                         │
│ echo '{"mode":"windsurf","provider":"proxy","proxyUrl":"http://localhost:9999"}' | bin/launch_windsurf_piped.sh
│                                                                            │
│ With key index 1:                                                          │
│ echo '{"mode":"windsurf","provider":"proxy","proxyUrl":"http://localhost:9999","keyIndex":"1"}' | bin/launch_windsurf_piped.sh
│                                                                            │
│ With key index 2:                                                          │
│ echo '{"mode":"windsurf","provider":"proxy","proxyUrl":"http://localhost:9999","keyIndex":"2"}' | bin/launch_windsurf_piped.sh
│                                                                            │
│ With window name:                                                          │
│ echo '{"mode":"windsurf","provider":"proxy","proxyUrl":"http://localhost:9999","windowName":"my-project"}' | bin/launch_windsurf_piped.sh
│                                                                            │
│ Dry run (test):                                                            │
│ echo '{"mode":"windsurf","provider":"proxy","proxyUrl":"http://localhost:9999","dryRun":true}' | bin/launch_windsurf_piped.sh
│                                                                            │
│ Gemini AI Studio:                                                          │
│ echo '{"mode":"studio"}' | bin/launch_windsurf_piped.sh                   │
│                                                                            │
│ Gemini Chat:                                                               │
│ echo '{"mode":"chat"}' | bin/launch_windsurf_piped.sh                     │
│                                                                            │
│ Gemini Studio (with key index 1):                                         │
│ echo '{"mode":"studio","keyIndex":"1"}' | bin/launch_windsurf_piped.sh    │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ JSON CONFIGURATION TEMPLATE ─────────────────────────────────────────────┐
│                                                                            │
│ Create a file (e.g., launch_config.json):                                 │
│                                                                            │
│ {                                                                          │
│   "mode": "windsurf",                                                      │
│   "provider": "proxy",                                                     │
│   "proxyUrl": "http://localhost:9999",                                    │
│   "keyIndex": "1",                                                         │
│   "windowName": "my-workspace",                                            │
│   "model": "gemini-2.0-flash-thinking-exp"                                │
│ }                                                                          │
│                                                                            │
│ Then launch:                                                               │
│ cat launch_config.json | bin/launch_windsurf_piped.sh                     │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ AVAILABLE OPTIONS ───────────────────────────────────────────────────────┐
│                                                                            │
│ CLI Arguments:                                                             │
│   --mode windsurf          Launch in Windsurf mode                        │
│   --provider proxy         Use HIGH-GRAVITY proxy                         │
│   --proxy-url URL          Proxy endpoint (http://localhost:9999)         │
│   --api-key KEY            Direct API key input                           │
│   --key-index N            Select key by index (1-based)                  │
│   --window-name NAME       Logical window/profile name                    │
│   --model MODEL            Model label for profile                        │
│   --dry-run                Prepare without launching                      │
│   --check                  Check key validity only                        │
│                                                                            │
│ JSON Keys (for piping):                                                    │
│   mode                     "windsurf", "studio", or "chat"                │
│   provider                 "proxy" or "direct"                            │
│   proxyUrl                 HIGH-GRAVITY proxy URL                         │
│   apiKey                   Direct API key input                           │
│   keyIndex                 Key index (1-based, as string or int)          │
│   windowName               Window/profile name                            │
│   model                    Model label                                    │
│   dryRun                   true/false - prepare without launching         │
│   check                    true/false - check key validity only           │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
